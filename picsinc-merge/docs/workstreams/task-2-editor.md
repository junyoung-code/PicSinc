# ② 영역 선택과 겹침 수정

## 역할

사용자가 “어느 사진의 어느 부분을 가져올지” 화면에서 지정하도록 합니다.

## 핵심 구현

- 모바일 편집기는 원본에서 검출한 공통 ID를 선택하고, 윤곽선 점·브러시·지우기로 다듬게 합니다. 확대·이동은 원본 좌표와 분리합니다.
- 저장된 선택 영역을 다시 표시합니다. 기본 화면은 사진·ID·직접 다듬기·저장만 보여주고, 첫 ID 선택 뒤 사용 방식 바텀시트에서 그대로 사용 또는 상세 편집을 고릅니다. 확대와 도구는 어두운 상세 수정 화면으로 모읍니다. 상세 화면의 완료는 로컬 변경만 유지합니다.
- 동시 저장 충돌 후 서버 마스크가 바뀌어도 미저장 초안은 유지합니다. 사용자가 명시적으로 버리고 불러올 때만 대체합니다. 검출 마스크는 순차 디코딩해 모바일 메모리 사용을 제한합니다.
- 여러 참여자의 선택 영역이 겹치는 부분을 표시합니다.
- 겹친 부분에 사용할 보정본을 고르거나 브러시로 영역별 출처를 지정하게 합니다.
- 개인 선택은 명시적인 완료 버튼에서 원본 크기의 흑백 PNG와 선택 ID를 ①의 저장 기능에 전달합니다. 드래그 중 서버 저장은 하지 않습니다.
- 기존 편집기는 대표자의 공동 겹침 수정에 재사용합니다. `overlapOnly`로 개인 편집과 합성 버튼을 숨기고 `onSaved`로 저장 완료를 알립니다.
- 윤곽선 수정은 이동한 점이 바꾼 픽셀만 갱신해, 손대지 않은 마스크 픽셀·구멍·분리된 영역을 유지합니다. 화면용 마스크만 축소하고 저장은 원본 해상도를 유지합니다.
- 점 이동은 단순화 전 실제 경계에서 이웃 점 사이 구간을 교체합니다. 이동 완료·취소 때 편집점을 다시 추출하지 않고 유지하며, 브러시·지우기와 새 마스크 로딩 때만 다시 추출합니다.
- 기존 겹침 편집기의 마스크 업로드·보정본 검출·병합은 공통 원격 클라이언트를 사용합니다. 작업 대기·진행 중에는 상태를 표시하고 저장된 결과가 준비된 뒤 화면에 적용합니다. 오류가 나면 편집 초안을 유지합니다.
- 두 편집기의 Canvas 이미지·마스크 로더는 익명 CORS 모드로 읽어 비공개 Storage 서명 URL로 이동한 뒤에도 픽셀을 읽을 수 있게 합니다. 같은 출처의 자산 API에서 참여 권한을 검사합니다.

## 연결 범위

화면을 축소해서 보여도 선택 위치는 원본 사진과 맞도록 합니다. 제품 동작은 [요구사항](../../MASTER_SPEC.md)을 따릅니다. 저장은 [①](task-1-session.md), 최종 사진 생성은 [③](task-3-composition.md)이 담당합니다. 고급 사진 보정 도구는 만들지 않습니다.

## 완료 기준

- A와 B가 각각 같은 원본의 ID를 고르고 윤곽선 점을 조정할 수 있습니다.
- 확대 전후 좌표, 취소된 터치, 내부 구멍과 분리된 영역 보존을 기능 옆 테스트로 확인합니다.
- 겹침을 확인하고 사용할 보정본을 지정할 수 있으며, 겹친다는 이유로 작업이 막히지 않습니다.
- 저장 후 다시 열어도 개인 선택과 공동 겹침 수정이 유지됩니다.
- 직접 업로드와 작업 조회는 공통 클라이언트 검증에 포함하고, 서명 URL로 받은 사진·마스크의 Canvas 표시와 선택 저장은 통합 브라우저 검사에서 확인합니다. 윤곽·좌표·겹침 회귀는 `node --import tsx --test src/features/region-editor/*.test.ts`로 확인합니다.

진행 상황은 [STATE.md](../../STATE.md)에서만 관리합니다.
